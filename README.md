# 🌍 Страны мира

**Скретч-карта путешествий: где побывали и куда мечтаете.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/world-map/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- 196 стран с флагами и русскими названиями (Intl.DisplayNames)
- Прогресс по 6 континентам и процент мира
- Достижения и список мечты
- Поиск и «поделиться результатом»

## Стек

JavaScript, Intl API. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/world-map.git
cd world-map
python3 -m http.server 8000
```
